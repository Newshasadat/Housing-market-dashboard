# عناوین فارسی نمودارهای داشبورد تحلیل بازار مسکن

این بخش شامل عنوان‌های فارسی پیشنهادی برای نمودارها و شاخص‌های داشبورد
Power BI پروژه تحلیل بازار مسکن است. عنوان‌ها با لحنی رسمی و مناسب
گزارش‌دهی و ارائه مدیریتی تنظیم شده‌اند.

## نکات مربوط به یکپارچگی عنوان‌ها

-   عنوان نمودارها کوتاه، روشن و رسمی انتخاب شود تا فضای داشبورد شلوغ
    نشود.
-   در نمودارهای مشابه، از عبارت‌های یکسانی مانند «به تفکیک منطقه»، «به
    تفکیک نوع ملک» و «میانگین قیمت» استفاده شود.
-   واحد اندازه‌گیری شاخص‌ها، مانند درصد، مترمربع یا واحد پولی، در عنوان
    یا برچسب محور مشخص شود.
-   در عنوان نمودارها میان «قیمت خرید»، «قیمت پیشنهادی» و «قیمت هر
    مترمربع» تمایز حفظ شود.
